# Product image sources

The BLE model thumbnails are unmodified product images sourced from the manufacturers' public product pages. They are used only to identify the selected scooter model inside MyNaviScooter.

- Segway ZT3 Pro, F3 Pro, MAX G3 and GT3: official Segway product-image assets from `segway.com` / `ninebot.com`.
No generated or approximate scooter render is used for these four Segway model thumbnails.

Unknown or not-yet-listed scooters use a deliberately generic MyNaviScooter-branded
illustration. It is never presented as a specific manufacturer model.
